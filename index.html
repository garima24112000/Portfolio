Ops Copilot — Autonomous Incident Triage Agent

LedgerLine — Distributed Payment & Ledger Platform

Built a production-style payment gateway of four Java 21 and Spring Boot services, focused on financial correctness, concurrency safety, and reliable event delivery. Implemented a PostgreSQL-backed double-entry ledger with database-enforced balance invariants, append-only journal entries, idempotent payments, refunds through reversing entries, and reconciliation for uncertain payment states.

Designed an event-driven architecture using a transactional outbox and Kafka so ledger updates and payment events commit atomically. Added HMAC-signed webhooks with retry topics, dead-letter recovery, merchant isolation, and Redis token-bucket rate limiting shared across service replicas.

Deployed to AWS EKS and RDS using Docker, Kubernetes, Helm, Terraform, Lambda, S3, ECR, and GitHub Actions with OIDC-based AWS authentication. The deployment was verified and then torn down with a scripted teardown; it is not kept running. Added Prometheus and Grafana observability, JUnit and Testcontainers integration tests, and k6 load tests that end with a ledger audit.

A duplicate-request test of 600 keys with 10 concurrent requests each produced 600 payments and 0 duplicates. Local load testing sustained 231 requests/second at 176 ms p99 with 0% errors before reaching a shared-ledger-row contention boundary. Diagnosed the bottleneck through PostgreSQL lock inspection, Grafana latency metrics, and connection-pool telemetry while the ledger remained balanced with global net = 0.

Income Prediction Using Machine Learning

Built an end-to-end supervised learning pipeline to predict whether an individual earns more than $50K annually using 48,842 records from the 1994 U.S. Census Adult dataset.

Cleaned missing and duplicate records, grouped rare categories, engineered a capital-gain-versus-loss feature, encoded categorical variables, scaled numerical features, and applied SMOTE for class balancing. Decoding CO2: Statistical Dive into Global Emissions

Team Project

Analyzed a country-level panel of global CO₂, economic, energy, and population data from 1982 onward to study how environmental and demographic factors relate to GDP and how those relationships changed over time.

Built a reproducible R and RMarkdown pipeline for cleaning, regression-based imputation, feature transformation, and visualization. Applied stepwise multiple regression with diagnostics, K-means clustering with PCA, and ARIMAX forecasting with structural-break analysis to examine country groupings and changing CO₂–GDP dynamics.

The country-level regression explained 69.2% of log-GDP variation, while the three-cluster solution achieved a 0.528 silhouette score. The aggregated model reached R² = 0.9956, and ARIMAX produced 0.24% test MAPE, identifying structural breaks in 1991, 2000, and 2009.

Tech Stack: R | RMarkdown | ggplot2 | dplyr | caret | forecast | strucchange | factoextra | K-means | PCA | ARIMAX

Image Captioning Bot

A multimodal computer vision and NLP system that converts input images into natural-language descriptions. The model was developed and tested using images and reference captions from the Flickr8k dataset.

A pretrained ResNet50 encoder converts each image into a 2,048-dimensional feature representation, while an LSTM decoder combines the visual features with word embeddings to generate captions sequentially.

The pipeline cleans and tokenizes captions, builds a filtered vocabulary, creates padded training sequences, caches extracted image features, and generates captions for unseen images using greedy decoding. Generated captions can also be spoken through a text-to-speech output.

Tech Stack: Python | TensorFlow | Keras | ResNet50 | LSTM | GloVe Embeddings | NumPy | NLTK | Flickr8k | pyttsx3
